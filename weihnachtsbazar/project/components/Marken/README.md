# Marken

Die kleinen Bausteine der Blätter: runder Aufkleber, Pillen und das Funkeln.

- `.sticker`: roter Kreis (124 px, −9° gedreht), `<b>` für die große Zeile, `<span>` für die kleine. `.sticker--gruen` für Kräuter.
- `.pille.pille--alk`: „mit Alkohol“, schwarz mit weißer Schrift.
- `.pille.pille--ohne`: „ohne Alkohol“, weiß mit schwarzer Schrift. Steht immer auf einer Farbkarte.
- `.gewicht`: weiße Pille für die Füllmenge der Kräuter.
- `svg.funkeln`: vierzackiger Stern in `rot`, mit `.funkeln--gruen` in `tanne`.

„Mit“ und „ohne Alkohol“ unterscheiden sich in der Helligkeit (schwarz/weiß) und im Wort, nicht nur in der Farbe.
