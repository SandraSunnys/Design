# EinzelBlatt

Ein einzelnes Produkt groß in Szene, zum Beispiel die Schokoladentafel im Dubai-Style: Foto links (55 % der Breite), Name, Pille, Allergene und Zutaten rechts.

`article.karte.karte--gross` füllt die Seite zwischen Kopf und Fuß. Der Name steht in 50 px, die Zutaten in 20 px. Die Mengenangabe („ca. 70 g“) gehört in den Aufkleber im Kopf.

Das Foto freigestellt liefern (PNG mit transparentem Hintergrund), damit es direkt auf der Farbfläche steht.
