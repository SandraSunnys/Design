# PralinenReihe

Vier Pralinensorten nebeneinander mit großen Fotos (184 px). Ideal für eine Gruppe wie „ohne Alkohol“.

Gleicher Rahmen wie `PralinenBlatt`, nur mit `.raster--4`. Die Namen stehen hier in 23 px, die Zutaten in 16 px. Namen bis ca. 17 Zeichen („Haselnusspralinen“) passen in eine Zeile.

Die Dachzeile kann die Gruppe nennen, z. B. „Handgemacht · ohne Alkohol“.
